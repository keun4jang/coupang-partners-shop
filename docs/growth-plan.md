## 4. 대기 중인 준비 작업

- 유튜브 분석: 완료(2026-09-28). metrics(views=true)가 유효 조회 비율(첫 1~2초 생존율 대용)과
  영상별 표(카테고리·상품명 포함)를 자동으로 찍는다. 평균 조회율은 넘기지 않은 사람 기준이라
  높게 나오므로(채널 65.8% vs 계속 시청 12.6%) 판정에 쓰지 않는다.
- 인스타 댓글→DM 자동화: 본인 계정은 기본 권한으로 가능(앱 검수 불필요).
  필요 권한 instagram_business_manage_comments · instagram_business_manage_messages.
  댓글당 7일 안에 DM 1회.
  **보류(2026-09-28):** 30일 동안 참여 계정 2 · 상위 릴스 댓글 0이라 지금 켜도 보낼
  DM 이 거의 없다. 초반 이탈(1단계)이 풀려 댓글이 생기기 시작하면 2단계에서 켠다.
  인스타 앱의 "연결된 도구 → 메시지 액세스 허용"은 모바일 앱에서만 확인 가능.
- 알리 DS 재인증: refresh_token 만료(2026-09-27 이전부터). 지금 access_token 으로 검색은 되지만
  만료되면 알리 상품 영상 매칭이 멈추고 전부 스톡 배경이 된다(영상 제작은 계속됨).
  재인증은 배경 소스를 바꿔 포맷 D 실험(X-003)과 섞이므로 10/6 판정 뒤에 한다.
- 쿠팡 수수료율: 확인 완료. 공식 기본 3%(클릭 후 24시간 안 거래액), 카테고리별 표는
  사이트에 없다. → 주문당 수수료를 올리는 수단은 "수수료율"이 아니라 "객단가"뿐이다.
